# Maven и работа с проектом

Этот документ описывает работу с проектом из исходников через Maven Wrapper.

## Требования

- Java `>= 21`
- PostgreSQL
- Linux, macOS или WSL для стандартных shell-команд

## Подготовка конфигурации

1. Скопируйте `config.ini-sample` в `config.ini`.
2. Заполните параметры БД, адреса приложения, администратора и пути хранения.
3. Убедитесь, что PostgreSQL доступен и база данных подготовлена.

## Запуск в режиме разработки

```bash
./mvnw spring-boot:run
```

Приложение будет запущено с использованием текущего `config.ini`.

## Сборка jar

```bash
./mvnw package
```

Готовый jar будет создан в директории `target/`.

## Запуск тестов

```bash
./mvnw test
```

## Полный цикл проверки

```bash
./mvnw verify
```

## Когда использовать этот документ

Этот сценарий нужен, если вы:

- разрабатываете проект из исходников;
- хотите локально запускать приложение без `install/install.sh`;
- собираете собственный jar для публикации в release.

## Структура важных файлов

- `src/main/java` - backend-код приложения
- `src/main/resources/templates` - Thymeleaf-шаблоны
- `src/main/resources/static` - CSS и JavaScript
- `config.ini-sample` - эталонный конфиг без чувствительных данных
- `install/install.sh` - автоматическая установка готового jar на Linux
- `docs/MAVEN.md` - работа с проектом через Maven Wrapper
- `docs/USER_MANUAL.md` - подробное руководство пользователя
