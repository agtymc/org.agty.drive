# Руководство пользователя AGTY/DRIVE

## 1. Что это такое

AGTY/DRIVE - это файловый сервис, который открывается в браузере. Он нужен для хранения файлов, раскладки по папкам, быстрого просмотра, скачивания и отправки ссылок другим людям.

Если говорить совсем просто, это ваш собственный аналог привычных облачных дисков:

- здесь можно хранить документы, фотографии, видео и другие файлы;
- можно быстро показать файл по ссылке;
- можно ограничить срок жизни файла или ссылки;
- можно работать без сложных программ, прямо в браузере.

## 2. Как войти в систему

1. Откройте адрес сервиса в браузере.
2. Введите логин и пароль.
3. Нажмите кнопку входа.

Если вам выдали ссылку-приглашение, сначала завершите регистрацию по этой ссылке, а затем войдите под своими данными.

## 3. Что находится на экране

После входа обычно видны:

- боковое меню с разделами;
- основная рабочая область с файлами и папками;
- кнопки создания папки, загрузки и переключения режима просмотра;
- строка поиска;
- таблица или плитки файлов.

## 4. Разделы

### Файлы
Главный раздел, где находятся ваши папки и файлы.

### Фото
Показывает изображения отдельной лентой, чтобы не искать их по папкам.

### Видео
Показывает видеофайлы отдельным списком или сеткой.

### Совместный доступ
Здесь собраны объекты, для которых уже созданы публичные ссылки.

## 5. Как создать папку

1. Откройте раздел `Файлы`.
2. Перейдите в нужную директорию.
3. Нажмите кнопку создания папки.
4. Введите название.
5. Сохраните изменения.

Если внутри папки пока ничего нет, система покажет сообщение `Папка пока пуста`.

Если на диске еще совсем ничего не создано, вы увидите сообщение `Диск пока пуст`.

## 6. Как загрузить файл

### Обычная загрузка

1. Откройте нужную папку.
2. Нажмите кнопку загрузки.
3. Выберите один или несколько файлов.
4. При необходимости заполните дополнительные свойства.
5. Нажмите сохранение.

### Перетаскивание

Можно просто перетащить файл мышью в окно сервиса.

### Вставка из буфера

AGTY/DRIVE умеет создавать файл прямо из буфера обмена:

1. Скопируйте текст или изображение.
2. Перейдите в нужный раздел сервиса.
3. Нажмите `Ctrl+V`.
4. Проверьте предпросмотр и имя будущего файла.
5. Сохраните.

## 7. Массовая загрузка

Если выбрать много файлов сразу, сервис покажет список загрузки.

В этом списке можно:

- видеть названия файлов;
- следить за ходом загрузки;
- понимать, какой файл завершен, а какой дал ошибку;
- удалить отдельный файл из очереди до завершения;
- выбрать действие при конфликте имени.

## 8. Если файл с таким именем уже существует

При совпадении имени система не должна молча перезаписывать файл.

Обычно будет предложено:

- `Отмена` - ничего не делать;
- `Перезаписать` - заменить существующий файл;
- `Пропустить` - оставить старый файл и не загружать конфликтный.

Если вы сомневаетесь, выбирайте `Пропустить`, чтобы не потерять текущую версию.

## 9. Время жизни файла или папки

AGTY/DRIVE поддерживает временные файлы.

Это означает:

- можно загрузить файл не навсегда;
- можно заранее указать дату и время удаления;
- после наступления срока объект удалится автоматически;
- связанные публичные ссылки и общий доступ тоже будут удалены.

### Как это работает

В форме добавления файла или в свойствах уже созданного объекта есть настройка автоматического удаления.

Обычно вы увидите:

- переключатель `Удалить автоматически`;
- поле `Время жизни`;
- быстрые варианты вроде `1 час`, `24 часа`, `неделя`, `месяц`.

Если автоматическое удаление выключено, поле времени не активно.

Если оно включено, выберите точную дату и время или одну из готовых предустановок.

## 10. Публичные ссылки

Публичная ссылка нужна, чтобы открыть файл или папку другому человеку без входа в ваш аккаунт.

### Что можно настроить

- название ссылки;
- срок действия;
- пароль;
- разрешение на просмотр;
- разрешение на скачивание.

### Что важно помнить

- если срок ссылки закончится, она перестанет работать;
- если сам файл удалится по времени жизни, ссылка тоже исчезнет;
- пароль лучше передавать отдельно от самой ссылки.

## 11. Быстрый просмотр

Рядом с файлами есть кнопка просмотра. Она открывает модальное окно.

Внутри можно:

- смотреть изображения;
- запускать видео;
- слушать аудио;
- читать текстовые файлы, если размер позволяет предпросмотр.

Если у файла нет поддерживаемого просмотра, кнопка остается на месте, но будет недоступна.

## 12. Скачивание

Можно скачивать:

- отдельный файл;
- целую папку архивом.

Если вам нужна только копия файла на компьютер, это самый простой способ.

## 13. Просмотр в режиме списка и сетки

### Список
Подходит для документов и случаев, когда важны имя, размер, дата и действия.

### Сетка
Подходит для фотографий, видео и других файлов, где важнее визуальный предпросмотр.

## 14. Значки и полезные мелочи

- значок часов под названием файла показывает дату автоматического удаления;
- значок глаза открывает предпросмотр;
- значок загрузки скачивает файл;
- значок шестеренки открывает действия и свойства.

## 15. Если что-то не получается

Проверьте по порядку:

1. Находитесь ли вы в нужной папке.
2. Не превышает ли файл допустимый размер.
3. Есть ли уже файл с таким же именем.
4. Не истек ли срок публичной ссылки.
5. Есть ли у вас права на этот объект.

Если проблема сохраняется, передайте администратору:

- что именно вы делали;
- название файла;
- примерное время ошибки;
- текст сообщения в окне, если он был показан.

## 16. Рекомендации по безопасной работе

- не публикуйте ссылки без необходимости;
- для важных файлов ставьте пароль на ссылку;
- проверяйте срок действия перед отправкой;
- не включайте автоматическое удаление, если файл нужен для постоянного хранения;
- для временной передачи наоборот используйте срок жизни, чтобы файл удалился сам.

## 17. Кратко

Если запомнить совсем коротко:

- `Файлы` - основная работа с папками и документами;
- `Фото` и `Видео` - быстрые медиабиблиотеки;
- `Совместный доступ` - все созданные вами ссылки;
- `Просмотр` - открыть без скачивания;
- `Время жизни` - удалить файл автоматически позже.
